# ADR-P0-001 — Knowledge-Core Prototype Boundary

**Status:** EXPERIMENTALLY SUPPORTED / NOT A PRODUCTION ADOPTION
**Date:** 2026-11-03
**Scope:** DECHIVE.WIKI only

## Context

DECHIVE.WIKI connects people, works, papers, concepts and events with verifiable, revision-bound knowledge. A public entry must be derived only from an approved immutable revision. Multi-parent taxonomy must not contain cycles; symmetric relations must not duplicate under concurrency.

## Experimentally supported decisions

- Keep stable UUID identities distinct from title, category code, and URL.
- Treat taxonomy edges as an acyclic directed graph, separate from semantic relation edges.
- Use a PostgreSQL transaction-level serialization mechanism for taxonomy writes. Fail closed when the transaction isolation mode is not supported by the tested guard.
- Enforce typed semantic relation rules and canonical symmetric edge ordering.
- Keep claim/source evidence tied to a revision and passage; freeze evidence edits after approval.
- Publish via an explicit coordinator that creates immutable snapshots and an atomic per-entity English public head + outbox entry.
- Derive public reads from the approved head only; ignore stale search-projection events.
- Apply media rights status at the moment of public lookup, not only at approval.

These claims are supported **only at the database experiment boundary**; see `P0_DB_TEST_REPORT.md`.

## Deliberately deferred decisions

- **Engine:** PostgreSQL versus Wikibase remains OPEN until the same fixtures are mapped and measured.
- **CMS:** Payload is a candidate, not the source of public truth; direct CMS bypass tests pending.
- **Public storage:** AWS S3/CDN architecture and real rights enforcement pending.
- **Authentication:** Private editorial RBAC and public reader permissions pending.
- **Search:** PostgreSQL FTS relevance and real search index latency pending.
- **Hosting:** AWS topology, price ceiling, encryption, restore and availability pending.
- **Localization:** Future locale schema is proposed but not implied by English-only prototype.

## Decision trigger

A formal production architecture selection requires documented G0–G3 proofs and updated ADRs. Do not merge this spike as proof of release readiness.
